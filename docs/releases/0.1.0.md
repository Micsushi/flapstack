# Flapstack 0.1.0 beta

Flapstack `0.1.0` is the first macOS beta. It includes the completed Stage 3
local-first Chat core and the Stage 4 feature-code pass.

## Core beta experience

- Create or open local projects and run durable Chats with Claude Code or Codex.
- Choose Claude, Codex, or local-only setup on first launch. Additional providers
  can be connected later in Settings.
- Keep provider credentials on the Mac. Flapstack does not require a hosted
  Flapstack account for local work.
- Use permissions, worktrees, checkpoints, file-change history, MCP controls,
  Usage, voice, and visible child-Chat lineage.

Provider connection labels come from current local CLI/credential state, not an
old onboarding flag. Explicit logout or credential removal is reflected in the
UI; a status-check failure does not delete local credentials.

## Optional Stage 4 beta features

These advanced surfaces are disabled by default. Enable only the ones you want
under **Settings → Beta Features**:

- Project Memory
- Orchestration
- Saved Workspaces
- Automations
- Planning & Task Board

Other Stage 4 work, including Agent Runtimes, Agent Profiles, portability,
advanced usage, and local-model controls, is included where exposed but remains
beta-supported. A visible feature is not a stable cross-platform support claim.

## Platform and installation

- macOS only for `0.1.0`; separate Apple Silicon and Intel DMGs.
- The `0.1.0` DMGs are intentionally unsigned and not notarized by Apple.
  macOS will show an unidentified-developer warning. Follow the installation
  steps in the macOS release runbook and verify the published SHA-256 checksum.
- Both DMGs must pass architecture inspection and bundled-runtime smoke before
  publication.
- No silent auto-update channel is enabled in this beta.
- GitHub downloads are public only after the repository itself is public or the
  DMGs are copied to a separate public download host.

This beta should not be promoted as stable until clean-profile Claude and Codex login,
restart, reconnect, idle, sleep/wake, and brief network-loss checks pass on the
exact candidate.
