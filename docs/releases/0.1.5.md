# Flapstack 0.1.5

Flapstack 0.1.5 brings provider setup, chat history, and local runtime improvements together.

- Detect Claude Code, Codex, Gemini via Antigravity, and Cursor sign-ins from one setup screen. Reuse detected sign-ins in one click, open native sign-in for selected providers, or enter an OpenRouter or NanoGPT API key inline.
- Switch reasoning effort during a Codex conversation and rewind to an earlier turn in the same native thread. Flapstack streams public reasoning summaries when the provider sends them.
- Apply Gemini permission changes on the next turn and inspect available models and their thinking options.
- Discover MCP tools on demand, jump between turns in long chats, and keep your place while expanding reasoning or tool details.
- Capture clean Git checkpoints without staging files and preserve excluded files and nested repositories during restore.

The contributor suite now focuses on behavioral checks for security, migrations, recovery, and provider lifecycles.

## Windows downloads

Public Windows installers require the Flapstack publisher certificate. This release provides macOS and Linux downloads.
