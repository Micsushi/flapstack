# Flapstack 0.1.3

Flapstack 0.1.3 improves daily project chats with Codex, Claude Code and Gemini through Antigravity.

- Start a global chat without choosing a project and resume it after restarting Flapstack.
- Move a conversation between the three providers with a preview of the context being transferred.
- Steer active Codex and Claude turns, queue follow-ups, and keep the partial answer when you stop a run.
- See Gemini context usage and manual compaction in the conversation. Connect project tools with explicit permission.
- Read a whole reply or a summary with local Kokoro speech. Flapstack can prepare the opening sentence while the reply streams.
- Find models and voice settings in the reorganized Settings screen. Legacy models remain available in the picker.

## Known limits

Large projects with many uncommitted changes can take several seconds to protect before a first answer. On Windows, Kokoro took 1.60 seconds to start on a newly streamed reply and 3.51 seconds on an uncached stored reply in testing. Long Codex conversations stalled in both Flapstack and the standalone client during qualification. Model access depends on the provider account.
