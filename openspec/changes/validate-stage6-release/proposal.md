# Change: Validate the integrated Stage 6 release

## Why

Stage 6 spans usability, onboarding, personalization, mobile, visual capture,
advanced workspaces, Runtime composition, organization usage, an
Obsidian-compatible project knowledge graph, performance, and distribution. One
exact candidate must prove the complete product together.

## What Changes

- Add one SHA-bound integrated matrix and candidate ledger.
- Prove clean install and Stage 5 upgrade across supported targets, retaining a Stage 4 legacy migration fixture.
- Exercise all Stage 6 features in one representative project/workflow.
- Prove same-folder Flapstack/Obsidian knowledge, graph, Git, and context behavior.
- Run security/privacy, usability/accessibility, performance, package, and docs gates.
- Perform independent review/fix rounds and record the release decision.

## Impact

- Affected specs: new integrated-stage6-release capability.
- Affected code: test matrices, candidate ledger, migration/package/security/
  usability/performance harnesses, release docs, and defect closeout.
